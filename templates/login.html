Self-hosted server

Create Sora on your server

Automated Docker setup supports Ubuntu / Debian. For other Linux, first install Docker and Docker Compose. Download the Sora service package from the release page, then select it here. Once created, use the same long invite code on Mac, Windows, and Android.

By default, it will choose the first available port from 5001 to 5010. If 5001 is taken, it will use subsequent ports. Please ensure ports are open in your cloud firewall/security group. Initial connection will trust this server's fingerprint; please confirm the IP is your own cloud server.
