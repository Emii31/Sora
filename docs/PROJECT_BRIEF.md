# Sora Project Brief

Sora is an affectionate female companion AI project derived from Miru.

## Requirements
- **Language**: English throughout first-party source, comments, prompts, UI, errors, documentation, and generated default content.
- **Branding**: Sora name, original logo/avatar, and eventually an animated 3D character.
- **AI Integration**: One AI connection setup shared by chat, memory, and vision. Avoid manual model selection. Investigate routing/discovery.
- **Inference**: Local inference and zero recurring service fees are the goal. Distinguish local app hosting from local inference.
- **Persona**: Affectionate female companion, emotional speech, speech recognition, wake word, interruption support, and microphone controls.
- **Camera/Screen**: Camera access on explicit request only. Screen capture handled separately.
- **Interface**: Dynamic-island-style interface on Linux and Android.
- **Functional Features**: Notes, reminders, calls/messages, and device tasks delegated by the owner.
- **Memory**: Shared long-term memory between laptop and phone, designed for disconnected use and synchronization.
- **Development**: Skill acquisition through isolated changes, validation, version history, and rollback.
- **Safety**: Do not promise arbitrary code changes always succeed. No unreviewed code installation.
